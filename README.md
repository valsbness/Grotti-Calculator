# GROTTI — Workshop Calculator

Calculadora web para el taller Grotti, basada en la estructura y tarifas visibles en la calculadora Benny's de referencia.

## Archivos
- `index.html` — estructura
- `style.css` — diseño Grotti
- `script.js` — precios, cálculos, descuentos y funcionamiento
- `assets/grotti-logo.jpeg` — logo proporcionado

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos manteniendo la carpeta `assets`.
3. En Settings → Pages, selecciona la rama principal y `/root`.
4. Guarda y espera a que GitHub Pages publique la web.

## Cambiar precios
Los precios están al inicio de `script.js`, en los arreglos `habitual` y `full`.
El cuarto número de cada línea es el precio de venta.
